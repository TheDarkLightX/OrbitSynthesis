# Parameter budget for restoring quasi-primal controller patchability

**Status:** DERIVED finite-algebra results with exhaustive unary calibrations through six carrier elements and an explicit unbounded family. The terminology introduced here is provisional pending deeper literature review. Pointed enrichments, automorphism bases/fixing numbers, and homogeneity are classical adjacent notions; this invariant is not claimed to be standard or novel until prior art is resolved. Tau-independent. Not Lean-checked.

## 1. From zero parameters to all parameters

`QUASIPRIMAL_DEMI_EQUATIONAL_CHARACTERIZATION.md` proves that a finite quasi-primal algebra Q has universal greatest-region behavior for original-signature term safety exactly when Q is demi-semi-primal.

`QUASIPRIMAL_PARAMETERIZED_CONTROLLER_COLLAPSE.md` proves that if **all** carrier elements may be named as parameters/constants, every finite controller table is representable and ordinary greatest-fixed-point safety is recovered.

There is a natural interpolation between these endpoints.

Let

`C subseteq Q`

be a set of carrier elements that the synthesized controller is allowed to name.

Form the pointed expansion

`Q_C`

by adding one nullary symbol for each element of C.

A `C`-parameterized controller is simply an original-signature term controller of `Q_C`.

## 2. What naming C does to partial symmetries

Because Q already has a discriminator term, adding constants preserves quasi-primality.

Subalgebras of `Q_C` are exactly the Q-subalgebras containing C.

An internal isomorphism

`phi:S -> T`

of `Q_C` is exactly an original Q-isomorphism between C-containing subalgebras satisfying

`phi(c)=c`

for every c in C.

The global automorphism group is

`Aut(Q_C)=Aut(Q)_(C)`,

the pointwise stabilizer of C.

Therefore the exact demi boundary applies to each parameter set separately.

### Theorem 1 -- pointed patchability criterion

For finite quasi-primal Q and `C subseteq Q`, the following are equivalent:

1. every C-fixing internal isomorphism between nontrivial C-containing subalgebras extends to a global automorphism fixing C;
2. the pointed expansion `Q_C` is demi-semi-primal;
3. every finite single-equation safety game over Q has a greatest winning domain when controller coordinates may use exactly the named constants from C in addition to the original signature.

This is `QUASIPRIMAL_DEMI_EQUATIONAL_CHARACTERIZATION.md` applied to `Q_C`.

## 3. Provisional invariant

Define the **parameter patchability number**

`kappa_patch(Q)
 = min { |C| : C subseteq Q and Q_C is demi-semi-primal }`.

This name is repository terminology for now.

Operationally it is the minimum number of carrier constants that must be made available to the controller language so that universal greatest-region patchability is restored.

Endpoints:

- `kappa_patch(Q)=0` iff Q is already demi-semi-primal;
- `kappa_patch(Q)<=|Q|` trivially, because naming the whole carrier makes every finite function available.

## 4. Monotonicity of good parameter sets

### Lemma 2

If C is good, meaning `Q_C` is demi-semi-primal, then every superset

`D superseteq C`

is good.

### Proof

Take any internal isomorphism

`phi:S->T`

of `Q_D`.

Then S,T contain D and therefore C, and phi fixes D pointwise, hence fixes C. So phi is also an internal isomorphism of `Q_C`.

Since `Q_C` is demi, phi extends to some global automorphism g of Q fixing C.

Because D is contained in S and phi fixes D, the extension g agrees with phi on D and therefore fixes every element of D.

Thus g is an automorphism of `Q_D`. QED.

So the family of good parameter sets is upward closed.

## 5. Generating-set upper bound

### Lemma 3

If C generates Q as an algebra, then C is good.

### Proof

Any subalgebra of Q containing C must contain `Sg_Q(C)=Q`.

Thus the only C-containing subalgebra is Q itself. Every internal isomorphism of `Q_C` is already a global automorphism fixing C. QED.

Hence

`kappa_patch(Q) <= d(Q)`,

where d(Q) is the minimum algebraic generating-set size.

This bound can be very loose.

## 6. It is not the ordinary fixing/base number

The graph-theoretic fixing number / permutation-group base size asks for the minimum C whose pointwise stabilizer in `Aut(Q)` is trivial.

`kappa_patch` asks something different:

> after fixing C, do **all partial internal isomorphisms** extend to global automorphisms?

A nontrivial global stabilizer is allowed as long as it has the right extension property.

Conversely, killing the existing global automorphisms need not eliminate nonextendable partial symmetries.

Concrete separation below: the first six-element unary witness has global automorphism group generated by the swap of two leaves, so one leaf is a fixing set of size 1; nevertheless `kappa_patch=2`.

Thus ordinary symmetry breaking and partial-symmetry patchability are distinct invariants.

## 7. Complete discriminator+one-unary calibrations

Let

`D_n={0,...,n-1}`

and for every unary map

`u:D_n->D_n`

form

`A_u=(D_n; discriminator, u)`.

Because the discriminator is basic, these are finite quasi-primal algebras.

Subalgebras are exactly nonempty u-invariant subsets. Internal isomorphisms are bijections between invariant subsets commuting with u. Global automorphisms are permutations commuting with u.

`experiments/unary_discriminator_parameter_patchability.py` exhausts every unary map for n<=6 and every relevant parameter set until the minimum is found.

### n=4

All `4^4=256` unary maps:

- 100 have `kappa_patch=0`;
- 156 have `kappa_patch=1`;
- none needs 2.

### n=5

All `5^5=3125` unary maps:

- 575 have `kappa_patch=0`;
- 2550 have `kappa_patch=1`;
- none needs 2.

### n=6

All `6^6=46656` unary maps:

- 5526 have `kappa_patch=0`;
- 38790 have `kappa_patch=1`;
- 2340 have `kappa_patch=2`;
- none needs more than 2.

Thus carrier size six is minimal inside this complete one-unary discriminator laboratory for observing parameter budget 2.

## 8. A minimal six-element witness

Take

`u=(0,0,0,3,3,5)`,

meaning

- `u(0)=0`;
- `u(1)=u(2)=0`;
- `u(3)=3`;
- `u(4)=3`;
- `u(5)=5`.

Its unary functional graph has three rooted-star components:

- `{0,1,2}`: root 0 with two leaves;
- `{3,4}`: root 3 with one leaf;
- `{5}`: isolated fixed root 5.

These components have pairwise distinct sizes 3,2,1.

No singleton parameter set is good.

Examples of surviving nonextendable partial isomorphisms:

- naming 0 still allows the pointed partial swap `3 <-> 5` on subalgebras `{0,3}` and `{0,5}`;
- naming 3 still allows `0 <-> 5` while fixing 3;
- naming 5 still allows `0 <-> 3` while fixing 5.

Naming two appropriately chosen components suffices. For example

`C={0,3}`

is good.

The exact checker finds several good pairs, including `{0,3}`, `{0,5}`, `{3,5}` and variants using leaves that force their roots.

Therefore

`kappa_patch(A_u)=2`.

## 9. Unbounded star family

The six-element witness suggests the general mechanism.

For `m>=1`, construct `Q_m` with:

- the ternary discriminator d;
- one unary operation u;
- m disjoint rooted-star components `K_1,...,K_m`;
- component `K_i` has exactly i elements: one fixed root `r_i` and `i-1` leaves mapping to `r_i`.

Thus

`|Q_m|=1+2+...+m=m(m+1)/2`.

The component sizes are pairwise distinct.

### Theorem 4 -- unbounded parameter patchability

`kappa_patch(Q_m)=m-1`.

### Lower bound

Let C have fewer than m-1 elements.

Each named element lies in one component. Therefore at least two components, say `K_i` and `K_j`, are completely untouched by C.

Let `cl(C)` be the unary closure of C; it lies entirely in the components touched by C.

The set

`S=cl(C) union {r_i,r_j}`

is a C-containing subalgebra.

Define phi on S by:

- fix `cl(C)` pointwise;
- swap `r_i` and `r_j`.

Within S the two untouched roots are just fixed points of u, so phi is an automorphism of the pointed subalgebra S.

If phi extended to a global automorphism of Q_m, that automorphism would send the full u-component `K_i` to `K_j`.

But global automorphisms preserve component cardinality and `|K_i|!=|K_j|`.

Contradiction.

Hence every good C touches at least m-1 components, so

`|C|>=m-1`.

### Upper bound

Name the roots of any m-1 components, say

`C={r_1,...,r_(m-1)}`.

Take a C-fixing internal isomorphism

`phi:S->T`

between C-containing u-invariant subalgebras.

All named roots are fixed.

The remaining root `r_m`, if present, must also map to itself: fixed points map to fixed points, the other roots are already occupied by their fixed images, and phi is injective.

Thus every component root occurring in S is fixed and S,T contain the same roots.

Any leaf x under root r_i satisfies

`u(phi(x))=phi(u(x))=phi(r_i)=r_i`,

so phi maps selected leaves only to selected leaves of the **same** component.

Within each component it is therefore a partial bijection between two equally sized leaf subsets. Extend it arbitrarily to a permutation of all leaves of that component.

Taking these independent leaf permutations over all components yields a global automorphism of Q_m fixing C and extending phi.

So C is good and

`kappa_patch(Q_m)<=m-1`.

Combined with the lower bound:

`kappa_patch(Q_m)=m-1`. QED.

## 10. Consequence: an unbounded controller-language hierarchy

For every r>=0 there exists a finite quasi-primal algebra Q with

`kappa_patch(Q)=r`.

Take

`Q_(r+1)`.

Thus the controller-language spectrum is genuinely graded:

- 0 named parameters can be insufficient;
- 1 can still be insufficient;
- any prescribed finite parameter budget can be insufficient;
- once enough anchors are named, universal greatest-region patchability returns.

This is much sharper than the binary distinction between original terms and arbitrary-parameter polynomial functions.

## 11. Reactive interpretation

For a given finite quasi-primal Q and parameter set C:

- if `|C|` is below the patchability threshold, there exists a single-equation safety game whose C-parameterized term-winning domains have no greatest element;
- once C is good, every single-equation safety game has a greatest C-parameterized term-winning region computable by the pointed automorphism-orbit/stabilizer predecessor.

The theorem follows immediately by applying the exact demi characterization to `Q_C`.

So parameter budget is not merely a code-size issue. It can change the **lattice structure of controllable domains**.

## 12. Relation to homogeneity, pointed enrichment, and fixing numbers

Adjacent standard notions found in the literature include:

- **homogeneous algebra/structure:** isomorphisms between finitely generated substructures extend to automorphisms;
- **pointed enrichment:** expand an algebra by named constants;
- **fixing/determining number / permutation-group base size:** minimum points whose pointwise stabilizer is trivial;
- EPPA/coherent extension properties for partial automorphisms.

`kappa_patch` is closest to a **minimum pointed enrichment needed to make the relevant quasi-primal algebra demi-semi-primal/homogeneous with respect to its subalgebras**.

Current targeted searches have not found a standard name for exactly this minimum-cardinality invariant. Keep the repository name provisional.

## 13. Research consequences

### C1. Parameter-budget synthesis mode

The API should allow a controller parameter budget, not merely a Boolean `allow_parameters` flag.

For quasi-primal Q, increasing the allowed named set monotonically removes partial-symmetry constraints.

### C2. Optimize which parameters to name

Finding a minimum good C is a new finite combinatorial problem:

> hit enough nonextendable partial-isomorphism obstructions so that every remaining pointed internal isomorphism extends globally.

This resembles hitting set, but an anchor can also change the subalgebra family, not merely delete one symmetry edge.

### C3. Compiler path after threshold

Once C is good, use the orbit/stabilizer solver for `Q_C`; after naming the full carrier, use the unrestricted discriminator compiler.

### C4. Complexity target

Determine the complexity of computing `kappa_patch(Q)` from a finite algebra table, first for discriminator+unary algebras, then for arbitrary finite quasi-primal algebras.
