# One-point extension geometry across omega-categorical structures

**Status:** DERIVED comparative note; standard model-theoretic/combinatorial facts assembled to isolate a research parameter. No claim that the notion of one-point extensions or stabilizer orbits is new.

The purpose of this note is to understand why ABA is computationally unusual among familiar omega-categorical structures.

## 1. Restriction fibers / one-point extensions

For a countable omega-categorical structure M and a complete k-type `tau`, define its one-point extension fiber

`Ext_M(tau) = { tau' in T_(k+1) : tau'|_[k] = tau }`.

If `a` realizes `tau`, this fiber is canonically identified with the orbits of the pointwise stabilizer

`Aut(M)_a`

acting on the domain M: two possible new elements `b,c` give the same `(k+1)`-type over `a` iff an automorphism fixing `a` sends `b` to `c`.

Define the worst one-point extension width

`e_M(k) := max_{tau in T_k} |Ext_M(tau)|`.

Trivially,

`|T_(k+1)| = sum_{tau in T_k} |Ext_M(tau)|`

and

`|T_(k+1)| <= |T_k| e_M(k)`.

The key issue for computation is that a large `e_M(k)` does **not** necessarily imply that the extension relation is hard to represent symbolically.

## 2. Pure equality

Let M be a countably infinite set with equality only.

A complete k-type is a set partition of the k variable positions. Let the type have `b` equality blocks (b distinct realized elements).

A new element y can:

1. equal one of the b existing blocks; or
2. be different from every existing element.

Hence

`|Ext_eq(tau)| = b+1`.

The maximum occurs at `b=k`:

`e_eq(k)=k+1`.

The total number of k-types is the Bell number `B_k`.

**Inner ground:** adding one point chooses an existing equality class or creates one new class.

## 3. Dense linear order `(Q,<)`

A complete k-type is a total preorder on the variable positions: partition the variables into `b` equality blocks and linearly order those blocks.

For a type with b distinct ordered values, y can:

1. equal one of the b existing values; or
2. lie in one of the b+1 gaps (before all, between consecutive values, or after all).

Therefore

`|Ext_DLO(tau)| = 2b+1`

and

`e_DLO(k)=2k+1`.

The number of k-types is the ordered Bell/Fubini number

`sum_{b=1}^k S(k,b) b!`

(with the conventional `T_0` singleton separately).

**Inner ground:** one new point chooses a cut of a finite linear order, with equality positions interleaved with open gaps.

## 4. The countable random (Rado) graph

Take the usual irreflexive symmetric graph language.

A complete k-type is determined by:

1. a partition of the k positions into `b` equality blocks; and
2. a simple graph on those b distinct vertices.

Thus

`|T_k| = sum_{b=1}^k S(k,b) 2^(binom(b,2))`.

For a type with b distinct vertices, a new y can:

1. equal one of the b existing vertices (b choices); or
2. be a fresh vertex with any chosen adjacency subset of the b old vertices (`2^b` choices).

The Rado extension property realizes every fresh adjacency pattern. Hence

`|Ext_RG(tau)| = b + 2^b`

and

`e_RG(k) = k + 2^k`.

**Inner ground:** a new distinct vertex independently chooses adjacency/non-adjacency to each existing vertex.

## 5. Countable atomless Boolean algebra

For ABA, a complete k-type is a nonempty support `S` on the `2^k` Boolean Venn cells. Let

`s=|S|`.

Equivalently, the finite Boolean subalgebra generated by the tuple has exactly s nonzero atoms (atoms of the generated finite subalgebra, not of the ambient atomless BA).

Adding a new BA element y refines each generated atom independently in exactly three ways:

1. entirely outside y;
2. entirely inside y;
3. split into a nonzero outside part and a nonzero inside part.

Therefore

`|Ext_ABA(tau)| = 3^s`.

The maximum support size is `2^k`, so

`e_ABA(k)=3^(2^k)`.

**Inner ground:** every currently nonzero region independently undergoes a ternary refinement.

## 6. Comparison

Worst one-point extension widths:

| structure | `e_M(k)` |
|---|---:|
| pure equality | `k+1` |
| `(Q,<)` | `2k+1` |
| Rado graph | `k+2^k` |
| atomless Boolean algebra | `3^(2^k)` |

Thus ABA has enormously larger explicit extension branching than the familiar equality/order/random-graph symmetries.

Yet `ABA_EXTENSION_ROBDD.md` proves that, under the minimum-width Venn-support code, the relation describing **all** one-variable ABA extensions has exactly

`5*2^k`

ROBDD nonterminal nodes.

So for ABA:

- maximum number of explicit extension choices: `3^(2^k)`;
- minimum binary type-code width: `2^k`;
- exact extension-relation ROBDD size: `5*2^k`.

This separation is the phenomenon to understand.

## 7. Explicit branching versus symbolic extension complexity

The standard invariant `e_M(k)` measures how many extension orbits a tuple stabilizer has. For synthesis, however, enumeration cost may be less important than whether the entire restriction/extension relation has a succinct representation under a useful type encoding.

We therefore introduce the following **working research question**, not a claimed standard invariant:

> Given an effectively omega-categorical structure M, how small can one simultaneously make (a) a computable encoding of complete k-types and (b) a Boolean/circuit representation of the one-point extension relation between the k- and `(k+1)`-type encodings?

Call this the **succinct extension presentation problem** inside this repository until the terminology is checked against the literature.

The nominal/supported-set literature already studies finite representations of orbit-finite structures for symmetries such as equality and total order, so the generic idea of finitely representing orbits is not new. What is specific here is to use extension-presentation size as an algorithm-selection parameter for ocLTL/Tau synthesis and quantifier elimination.

## 8. Why ABA may be unusually favorable

ABA combines two properties:

1. **minimum-width type coordinates:** the `2^k` Venn-support bits attain the information-theoretic lower bound exactly;
2. **factorized extension:** every support coordinate refines locally and independently by the same ternary rule.

This makes the extension relation linear in the code width even though the number of extension choices is exponential in that width.

That is a stronger computational fact than omega-categoricity alone.

## 9. Fraisse reading

The four examples can also be read through finitely generated substructures / one-point extensions:

- equality: finite sets;
- DLO: finite linear orders;
- random graph: finite graphs;
- ABA: finite Boolean subalgebras embedded in the atomless limit.

For ABA, adjoining one arbitrary BA element can split **every atom of the generated finite subalgebra simultaneously**, which explains the `3^s` branching. But because those splitting decisions are independent, the relation factors into local constraints.

This is the Noether-style explanation of the paradoxical combination "huge extension set, tiny extension relation".
