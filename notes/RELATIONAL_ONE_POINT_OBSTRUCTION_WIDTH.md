# One-point obstruction incidence width for monotone relational classes

**Status:** DERIVED finite relational theorem. This is a direct generalization of the graph classification in `MONOTONE_GRAPH_EXTENSION_CLASSIFICATION.md`. Terminology is provisional pending literature comparison.

## 1. Monotone relational class

Fix a finite relational signature L.

Call a finite-structure class K **relation-monotone** if whenever A belongs to K, deleting relation facts (tuples) while keeping the same underlying finite set also produces a structure in K.

This is the relational analogue of a graph class closed under deleting edges.

Let `M(K)` be the set of relation-fact-minimal forbidden structures: structures H outside K such that deleting any relation fact (and then removing isolated/unneeded points if desired) destroys that particular forbidden witness. For the cleanest statement below, take minimality under the partial order generated by deleting relation facts and vertices.

## 2. One-point response incidences

Fix an old structure A in K and add a fresh response element y.

Let `I(A,y)` be the finite set of all candidate positive atomic relation facts involving y and old elements of A that the synthesis fragment allows the response to choose independently.

Examples:

- graph: incidences are edges `E(y,a)`;
- k-uniform hypergraph: incidences are hyperedges containing y and k-1 old points;
- colored/multi-relation structures: incidences are relation-tagged tuples involving y.

A response code is a subset

`N subseteq I(A,y)`.

Because K is relation-monotone, the legal code family is downward closed.

## 3. One-point incidence degree of a forbidden structure

For a finite forbidden structure H and a distinguished vertex v, define

`deg_1(H,v)`

as the number of positive relation facts of H that contain v, counted as independently selectable incidences in the chosen coding convention.

Define the **one-point obstruction incidence width**

`omega_1(K) = sup { deg_1(H,v) : H in M(K), v in H }`.

For a finitely bounded class this is finite.

In simple graphs, `deg_1(H,v)` is ordinary graph degree and `omega_1(K)` is the maximum degree occurring in a minimal forbidden graph.

## 4. Response conflict hypergraph

For old A, define `C_K(A)` on vertex set `I(A,y)`.

A hyperedge F is an inclusion-minimal set of response incidences such that adding all incidences in F to y creates a forbidden K-configuration with the old structure A.

Then:

`N legal  iff  N contains no F in C_K(A)`.

Thus legal response codes are exactly independent sets of the conflict hypergraph.

### Theorem 1 — rank bound

Every conflict hyperedge has size at most `omega_1(K)`.

### Proof

A minimal illegal response code realizes some minimal forbidden H using y as the distinguished new point. The response incidences needed from y are exactly a subset of the relation facts of H containing that point. Minimality removes any redundant incidence. Hence conflict size is at most `deg_1(H,y)` and therefore at most `omega_1(K)`.

## 5. Exact dominant-response classification

### Theorem 2

Assume K has unbounded enough finite members for the relevant bases and use the minimal-forbidden convention above. Then the following are equivalent:

1. every fresh legal response family is union-closed;
2. every fresh legal response family is a Boolean cube `P(U_A)` for some individually admissible incidence set U_A;
3. `omega_1(K) <= 1`.

### Proof: (1) iff (2)

Legal families are finite and downward closed. Apply the downward+union-closed cube lemma from the graph case.

### Proof: (3) implies (1)

If every conflict has size at most 1, legality merely forbids a set of individual incidences. Hence the legal family is exactly the powerset of the remaining incidences and is union-closed.

### Proof: failure when omega_1>=2

Take a minimal forbidden H and distinguished v participating in at least two independently selectable positive relation facts.

Let A be the old structure obtained by removing v while retaining the remaining legal part of H.

By minimality, adding any proper subset of the v-incidences is legal whenever that subset does not already realize another forbidden witness. In particular choose an inclusion-minimal illegal incidence subset F of size at least 2.

Every proper subset of F is legal, but their union F is illegal. Hence the legal response family is not union-closed and has no greatest element containing all individually compatible choices.

The minimal conflict F itself is a finite certificate of dominant-response failure.

## 6. General maximal-response theorem

For arbitrary finite `omega_1(K)=r`, canonical maximal responses are complements of minimal transversals of `C_K(A)`.

Therefore response synthesis for upward targets reduces from all complete response types to a rank-r conflict-hypergraph problem.

This gives the hierarchy:

- r=0: no positive response incidence can participate in a forbidden pattern;
- r=1: unique greatest response after removing individually forbidden incidences;
- r=2: graph-like pairwise conflicts, maximal responses dual to minimal vertex covers of a conflict graph;
- fixed r>2: bounded-rank transversal structure;
- unbounded r: general hypergraph response conflict.

## 7. Examples

### Random graph / unrestricted relational random structure

No forbidden positive configurations:

`omega_1=0`.

Every response incidence may be selected simultaneously.

### Edgeless graph class

Minimal forbidden K_2 has degree 1 at each endpoint:

`omega_1=1`.

All adjacency incidences are individually forbidden, leaving the unique empty response.

### Henson K_n-free graphs

Minimal forbidden K_n has

`deg_1(K_n,v)=n-1`.

Hence

`omega_1=n-1`.

The conflict hypergraph over A is exactly the `(n-1)`-clique hypergraph.

### Forbid a matching m K_2

Every vertex of the minimal forbidden graph has degree 1, so

`omega_1=1`.

Fresh response families have a greatest element even though admissibility of an individual edge depends on the old structure's existing matching.

## 8. Synthesis corollary

For an upward response target W:

- if `omega_1<=1`, one greatest response suffices;
- for general r, test only canonical maximal responses or operate symbolically on the rank-r conflict formula;
- if the conflict formula has low incidence treewidth/VC dimension/symmetry, use the knowledge-compilation/transversal backends from `RESPONSE_KNOWLEDGE_COMPILATION.md`.

Thus one-point obstruction width is a theory-level parameter controlling the **arity of response incompatibility**.

## 9. Relation to polymorphisms

A semilattice polymorphism may force closure of legal relation tuples under a global join, but `omega_1` is a different combinatorial invariant:

- it is defined from minimal forbidden one-point configurations;
- it is local to a chosen incidence coding/fragment;
- it directly predicts response conflict rank.

A major research question is whether polymorphism identities bound or characterize one-point obstruction width in important omega-categorical reduct classes.

## 10. Higher-order research questions

1. Extend from relation-monotone classes to hereditary induced-substructure classes where both positive and negative incidences matter; the response conflict object will become a signed constraint hypergraph rather than a downward family.
2. Relate `omega_1` to finite boundedness, free amalgamation, and forbidden homomorphism dualities.
3. Determine whether fixed `omega_1` plus bounded incidence treewidth yields FPT positive-mu-calculus synthesis.
4. Define multi-point obstruction width for response blocks containing several new output elements.
5. Classify homogeneous graph/digraph/hypergraph families by one-point obstruction width and maximal-response circuit complexity.
