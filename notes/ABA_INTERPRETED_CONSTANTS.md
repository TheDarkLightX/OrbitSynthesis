# Atomless Boolean algebra with finitely many interpreted constants

**Status:** DERIVED paper proof; standard-model-theoretic ingredients, exact formula not claimed novel; computational exploitation is an active research direction; Lean pending.

This extends the support representation from pure ABA to the nontrivial setting emphasized in Asor's GS/NSO construction: the Boolean algebra is fixed and its language contains interpreted constants for BA elements. Any particular finite formula mentions only finitely many of them.

## 1. The constant partition

Let `B` be a countable atomless Boolean algebra and let

`C={c_1,...,c_m} subseteq B`

be the finite set of interpreted constants relevant to a formula.

Let `A_C` be the finite Boolean subalgebra of `B` generated by `C`, and let

`D_1,...,D_r`

be its nonzero atoms **inside the finite subalgebra `A_C`**.

Important: these are not atoms of the ambient atomless BA. Every `D_j` is a nonzero element of `B` and can still be split into smaller nonzero BA elements.

Define the **constant partition rank**

`rho(C) := r`.

Equivalently, `rho(C)` is the number of nonzero Venn regions cut out by the constants.

Always

`1 <= rho(C) <= 2^m`.

The upper bound is attained exactly when every constant Venn region is nonzero.

## 2. Complete types over the constants

Fix `k` BA variables `X=(x_1,...,x_k)`. For every constant region `D_j` and variable minterm `X^A`, where

`A in {0,1}^k`,

consider the joint cell

`D_j X^A`.

For each fixed `j`, the `2^k` joint cells partition `D_j`. Therefore at least one of them is nonzero.

A tuple `X` determines a support

`S_j(X) = { A : D_j X^A != 0 }`

for every constant region, with

`empty != S_j(X) subseteq {0,1}^k`.

## Theorem 1 — exact type count over C

Complete parameter-free types in the language expanded by the named constants `C` (equivalently complete types over the parameter set `C`) are in bijection with tuples

`(S_1,...,S_r)`

of nonempty subsets of `{0,1}^k`.

Consequently

`|T_k(C)| = (2^(2^k)-1)^rho(C)`.

### Proof

**Determination.** Atomless Boolean algebra has quantifier elimination. After treating `C` as named parameters, every formula is equivalent to a Boolean combination of atomic Boolean equations involving `X` and the constants. Every Boolean function has minterm normal form in `X` with coefficients from the finite subalgebra generated by `C`. Each coefficient is a union of some `D_j`. Therefore the truth of every atomic equation is determined by which joint cells `D_j X^A` are zero, hence by `(S_1,...,S_r)`.

**Separation.** If two support tuples differ, some joint cell `D_j X^A` is zero in one and nonzero in the other. The atomic formula `D_j X^A=0`, where `D_j` is a Boolean term in `C`, distinguishes them.

**Realization.** For each `D_j`, choose an arbitrary nonempty support `S_j`. Because `D_j` is nonzero in an atomless BA, split it into `|S_j|` pairwise disjoint nonzero pieces, index them by `A in S_j`, and reconstruct the variables by joining pieces whose bit `A_i` is 1. Different `D_j` are disjoint, so the constructions combine independently.

Thus every support tuple is realizable and the count follows.

## 3. Exact one-variable extension count

Suppose a realized k-type over `C` has a total of

`s = sum_j |S_j|`

nonzero joint cells.

Adding one new BA variable independently refines each active joint cell into

- left only,
- right only,
- both.

Hence it has exactly

`3^s`

complete `(k+1)`-type extensions over `C`.

Adding `q` new variables gives

`(2^(2^q)-1)^s`

extensions.

## 4. Support Booleanization extends unchanged

Introduce one support bit

`z_(j,A)`

for each constant region `j` and variable minterm `A`. The number of support variables is

`rho(C) * 2^k`.

The realizability constraint is local to each constant region:

`Valid_C(z) = AND_j OR_A z_(j,A)`.

Let a Boolean function be in minterm form

`f(X)= UNION_A d_A X^A`

with coefficients `d_A in A_C`. Write

`J_A={j : D_j <= d_A}`.

Then

`f(X)=0`

translates exactly to

`AND_A AND_{j in J_A} NOT z_(j,A)`.

Similarly `f(X)!=0` is the OR of the corresponding support bits.

So the support-level propositional translation works for finitely many interpreted constants just as it does in the pure ABA signature.

## 5. Extension ROBDD with constants

When one new BA variable is introduced, each support bit `z_(j,A)` has two refinement bits and obeys

`z_(j,A) <-> (w_(j,A,0) OR w_(j,A,1))`.

There are

`N = rho(C) * 2^k`

such coarse joint cells. By `ABA_EXTENSION_ROBDD.md`, the exact extension relation has an ROBDD with

`5 rho(C) 2^k`

nonterminal nodes under the cell-local interleaved order.

The additional validity constraint `Valid_C` must also be maintained; the theorem here concerns the extension relation itself.

## 6. Why rho(C) can be dramatically smaller than 2^m

### Generic constants

If all `2^m` Venn regions of `m` constants are nonzero, then

`rho(C)=2^m`.

This is the worst case.

### Nested constants

If

`c_1 <= c_2 <= ... <= c_m`,

then the only potentially nonzero regions are

`c_1`,
`c_2 \ c_1`,
`...`,
`c_m \ c_(m-1)`,
`1 \ c_m`.

Hence

`rho(C) <= m+1`,

with equality when all these differences are nonzero.

### Pairwise disjoint constants

If `c_i c_j=0` for `i!=j`, then the nonzero regions are at most the individual `c_i` plus their common complement, so again

`rho(C) <= m+1`.

### A partition of 1

If `c_1,...,c_m` are pairwise disjoint nonzero and join to `1`, then

`rho(C)=m`.

Thus raw constant count can be a catastrophically poor complexity proxy.

## 7. Type-count comparison

For `m` constants in fully generic Boolean position (`rho=2^m`),

`|T_k(C)| = (2^(2^k)-1)^(2^m)`.

At the level of leading exponents this behaves like

`2^(2^(k+m))`.

For a nested family with `rho<=m+1`, the same count is only

`(2^(2^k)-1)^(m+1)`.

The ratio is enormous even for modest `m`.

## 8. Tau/NSO relevance

Asor's GS paper defines the interpreted-constant setting by assigning constant symbols to BA elements and emphasizes that it is the nontrivial case; it also notes that the finiteness arguments only need the constants occurring in a fixed finite subset of the signature.

Therefore `rho(C)` is a natural semantic parameter for Tau formulas:

> Before doing type enumeration or symbolic QE, compute the nonzero regions induced by the interpreted constants actually occurring in the specification.

If those constants have strong Boolean relations, support dimension may collapse before any temporal reasoning begins.

In a Lindenbaum-Tarski algebra, determining whether a constant Venn region is nonzero is the satisfiability question for the corresponding Boolean combination of the underlying sentences. This is exactly where the decidability of the base logic enters.

## 9. Research targets

1. Benchmark `rho(C)` on realistic Tau specifications rather than assuming the worst case `2^m`.
2. Integrate constant-region preprocessing into the support-BDD prototype.
3. Compare exact `rho(C)` preprocessing against Asor's coefficient/minterm QE representation.
4. Find syntactic sufficient conditions (nesting, disjointness, implication graphs) that bound `rho(C)` without enumerating all `2^m` Venn regions.
5. Extend the fixed-point complexity parameters from `(k,|Delta|)` to `(k,rho(C), realized Delta signatures)`.
6. Determine whether the constant partition can itself be represented symbolically when `m` is large but the relation structure is compact.
