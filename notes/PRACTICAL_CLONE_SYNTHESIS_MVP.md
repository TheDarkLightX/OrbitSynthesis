# Practical OrbitSynthesis MVP: clone-constrained controller synthesis

**Status:** working software specification and implemented vertical slice,
2026-08-14.

## Goal

Turn the project's finite-algebra and compiler theorems into one usable,
proof-carrying workflow:

```text
model -> realizability hierarchy -> safe domain -> strategy -> term DAG -> certificate
```

The input is independent of Tau: a finite carrier, explicit operation tables,
an explicit safety relation, and required initial states.

## Controller-semantics hierarchy

The pipeline reports four increasingly restrictive questions separately.

1. **Ordinary positional:** may choose any locally safe output.
2. **Semi-primal:** output must remain in the subalgebra generated by the
   observation.
3. **Demi-semi-primal:** additionally respect global automorphism orbits and
   stabilizers.
4. **Quasi-primal/internal groupoid:** respect every internal isomorphism
   between generated subalgebras.

This distinction is the practical content of the project's strict-separation
results. A model may be realizable in the first three modes and fail only at
the internal-groupoid level.

## Compilation boundary

The first original-signature backend recognizes exact Quackenbush

```text
Q=({0,1,2};d,u)
```

and accepts a total conservative strategy table. Each scalar output becomes an
internal-isomorphism-compatible coordinate-selector table. The compiler first
recognizes projections, `u`, and one-discriminator programs; otherwise it uses
the existing parameter-free orbit-selector compiler. Multiple scalar roots are
structurally hash-consed into one canonical `{d,u}` DAG.

This boundary is intentional. A compatible nonconservative table is not
silently compiled with named constants, because that would change the declared
original-signature problem.

## Certificate

The emitted JSON certificate binds:

- the canonical model hash;
- algebra and game census;
- results under each semantic class;
- selected maximal domain and total table;
- compiler backend and selector tables;
- canonical DAG nodes and roots;
- operation count and depth;
- semantic replay count;
- or a structured groupoid failure trace.

`verify_certificate` re-runs synthesis and exhaustively replays every compiled
DAG row.
