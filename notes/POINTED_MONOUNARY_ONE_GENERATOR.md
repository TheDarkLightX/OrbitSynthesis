# Nonempty pointed monounary extension reduces to one extra generator

**Status:** DERIVED pointed adaptation of Thomas Quinn-Gregson's 2026 monounary ultrahomogeneity argument, with an explicit counterexample showing why the empty-parameter demi case does not reduce in the same way. The source theorem and Corollary 3.11 are prior art. This note specializes them to the parameter-patchability oracle. Tau-independent. Not Lean-checked.

## 1. Source theorem

Quinn-Gregson proves for a monounary algebra A that

> A is ultrahomogeneous iff A is 1-ultrahomogeneous.

Here n-ultrahomogeneous means that every isomorphism between n-generated subalgebras extends to a global automorphism.

The proof uses a monounary orbit-combination lemma (Corollary 3.11): if an isomorphism between

`<x_1,...,x_n>` and `<y_1,...,y_n>`

has its first n-1 generator tuples in the same global orbit and also has x_n,y_n in the same 1-orbit, then the whole isomorphism extends to an automorphism.

Source: Thomas Quinn-Gregson, *Ultrahomogeneity and omega-categoricity of monounary algebras*, arXiv:2603.26616 (2026), Proposition 4.1 and Corollary 3.11.

## 2. Pointed setting

Let

`A=(A;u)`

be a finite monounary algebra and let

`C subseteq A`

be a finite set of named constants.

A pointed subalgebra must contain C.

A pointed internal isomorphism must fix every element of C.

For `x in A`, write

`<C,x>`

for the unary subalgebra generated by `C union {x}`.

## 3. Why nonempty C removes the demi/trivial-subalgebra mismatch

Demi-semi-primality conventionally ignores one-element subalgebras.

If C is nonempty, any pointed subalgebra contains C.

- If `|C|>=2`, every pointed subalgebra is already nontrivial.
- If `C={c}`, the only possible one-element pointed subalgebra is `{c}` itself, and its only C-fixing automorphism is the identity, which extends globally by the identity.

Thus for nonempty C:

> the pointed demi extension property is equivalent to the ordinary full extension property for all pointed subalgebra isomorphisms.

No exceptional trivial isomorphism can fail.

## 4. Pointed one-extra-generator property

Call `(A;u,C)` **1-over-C homogeneous** when every C-fixing isomorphism

`phi:<C,x> -> <C,y>`

extends to a global automorphism of A fixing C.

### Theorem 1

For finite nonempty C, the following are equivalent:

1. every C-fixing isomorphism between C-containing subalgebras extends to a global C-fixing automorphism;
2. `(A;u,C)` is 1-over-C homogeneous.

### Proof

`1 -> 2` is immediate.

For the converse, induct on the number n of generators in addition to C.

Fix an enumeration

`C=(c_1,...,c_r)`.

Suppose

`phi:<C,x_1,...,x_n> -> <C,y_1,...,y_n>`

is a C-fixing isomorphism with `phi(x_i)=y_i`.

By induction, the restriction

`phi|<C,x_1,...,x_(n-1)>`

extends to an automorphism of A. Hence the tuples

`(c_1,...,c_r,x_1,...,x_(n-1))`

and

`(c_1,...,c_r,y_1,...,y_(n-1))`

lie in the same global orbit.

By 1-over-C homogeneity, the restriction

`phi|<C,x_n> : <C,x_n> -> <C,y_n>`

extends to an automorphism. In particular x_n and y_n lie in the same 1-orbit.

Apply Quinn-Gregson's Corollary 3.11 to the complete generator lists

`(c_1,...,c_r,x_1,...,x_n)`

and

`(c_1,...,c_r,y_1,...,y_n)`.

It yields an automorphism extending phi.

Since phi fixes every c_i and the automorphism extends phi on the generated pointed subalgebra, the extension fixes C pointwise.

This closes the induction. QED.

## 5. Why C=empty is different for our demi oracle

The unpointed demi property ignores one-element subalgebras, while ordinary ultrahomogeneity does not.

This difference can hide the first obstruction from one-generated nontrivial checks.

### Smallest counterexample

Take the three-element unary algebra

`u=(0,0,2)`:

- 0 is a fixed root with leaf 1;
- 2 is an isolated fixed root.

The one-generated subalgebras are

- `<0>={0}`;
- `<1>={0,1}`;
- `<2>={2}`.

If one deliberately ignores trivial singleton subalgebras, there is no failing one-generated nontrivial isomorphism.

But

`{0,2}`

is a two-element subalgebra, and its root swap

`0 <-> 2`

is an internal automorphism that cannot extend globally: the full unary components at 0 and 2 are nonisomorphic.

So unpointed demi failure may first appear after **combining two trivial local types**.

This is why the kappa=0 test cannot simply reuse Proposition 4.1 with trivial subalgebras deleted.

## 6. Algorithmic consequence for kappa_patch

For discriminator+one-unary algebras:

### Candidate C=empty

Use the full demi test over nontrivial invariant subalgebras.

### Every candidate C!=empty

It suffices to enumerate the at-most-|A| distinct pointed closures

`<C,x>`

and all C-fixing isomorphisms between closures of equal size.

There is no need to enumerate arbitrary C-containing subalgebras.

This is a substantial reduction when many invariant subsets exist.

## 7. Finite calibration

Before the proof was extracted, an independent exact comparison was run over every unary map on carriers up to five elements and every nonempty parameter set C.

For n=5 this covered

`5^5 * (2^5-1) = 96,875`

pointed cases.

The full subalgebra-pair oracle and the one-extra-generator oracle agreed in every case.

For C=empty, the three-element counterexample above gives the expected disagreement between full demi and the artificially truncated one-generated-nontrivial test.

The finite campaign is evidence for the implementation; Theorem 1 is the proof.

## 8. Relation to the 2026 classification

Quinn-Gregson also gives explicit classifications of ultrahomogeneous and partial-homogeneous monounary algebras and shows strong links between these variants.

OrbitSynthesis should use those classifications rather than rediscovering the unpointed static theory.

The new pointed optimization problem remains different:

> choose a minimum constant set C such that the pointed expansion has the extension property.

Theorem 1 makes that optimization much more tractable in the monounary laboratory.
